# 한국어 문서 전환 설계

## 목표

한국인 심사위원이 FiTuna의 구조, 개발 방식, 검증 결과, 오픈소스 활용과
관리 정책을 별도의 번역 과정 없이 읽을 수 있도록 공개 Markdown 문서의 영문
설명을 한국어로 전환한다. 한국어 README 상단에는 주요 개발·검증 문서로 바로
이동할 수 있는 링크표를 둔다.

## 범위

- 저장소 최상위와 `docs/` 아래 Markdown 문서의 영문 제목·본문·표 설명을
  자연스러운 한국어로 번역한다.
- 이미 한국어인 문서는 유지하되, 문맥상 필요한 영문 설명만 한국어로 다듬는다.
- `README.en.md`와 `docs/superpowers/`는 번역하지 않는다.
- MIT 라이선스 원문, SPDX 식별자, 명령어, 코드, 로그, 파일명, 제품명, API와
  프로토콜 이름은 원문을 유지한다.

## README 문서표

한국어 `README.md`의 소개 영역 바로 아래에 개발 문서 안내표를 추가한다. 표에는
아키텍처, 개발·검증 방식, 기여 안내, 실측 결과, 오픈소스 활용, 라이선스 검증,
심사·재현 가이드를 연결한다. 각 행은 문서명과 심사위원 관점의 한 줄 설명으로
구성한다.

## 호환성

- 영문 제목을 참조하는 기존 앵커는 명시적 HTML `id`를 두거나 참조 링크를 함께
  고쳐 유지한다.
- 상대경로 링크, 표, Mermaid, 코드 블록의 구조를 보존한다.
- 번역 과정에서 수치, 버전, 날짜, 실측 결과와 기술적 주장을 바꾸지 않는다.

## 검증

- 저장소 내부 Markdown 링크의 대상 파일과 명시적 앵커가 존재하는지 검사한다.
- 번역 제외 대상에 의도하지 않은 변경이 없는지 `git diff`로 확인한다.
- 남은 영문 문장이 예외 범위인지 점검하고 Markdown 코드 블록의 짝을 검사한다.
